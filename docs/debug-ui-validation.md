## 発見して修正した問題

- 同じページへの再遷移でアニメーションと履歴が壊れる問題。
- 戻った後も一時ページのVisualElementが残る問題。
- 同一フレームでオープンボタンを生成すると重複する問題。
- ToggleGroupの項目がキーボードのSubmitで切り替わらない問題。
- 縦長の画面でUIが小さくなり、横並びボタンや長文が収まらない問題。
- 進捗バー内部がコントロールの高さを満たさない問題。
- Darkテーマの進捗バー、フォーカスしたラベル、Foldoutの文字が読みにくい問題。
- PCで保存した位置を狭い画面へ復元するとメニューが画面外に出る問題。復元・リサイズ時の補正とDetach時のコールバック解除を追加。
