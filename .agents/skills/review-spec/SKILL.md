# 仕様案をレビューする

[仕様ワークフロー](../../../docs/contributing/specification-workflow.md)に従い、作成を終えた提案を読む。
同じエージェントが別passで行ってよく、別エージェントの起動は必須ではない。

確認するのは、依頼にない要件の追加、既存仕様との矛盾、未定義の状態/取消/失敗/回復、
公開API・保存値・依存関係への影響、実際に観察できる受け入れ条件、仕様と過去の知見の混同。
UIでは狭い画面・両テーマ・Runtime/Editorの違いに関係するものだけ確認する。

結果はBlocking / 軽微な指摘 / 未決事項 / 採用可否 / ユーザー判断の要否と理由。
好みの提案で範囲を広げない。レビュー自体は状態を更新せず、ワークフローの採用条件へ判定を返す。
